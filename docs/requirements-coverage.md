Source and automated checks establish application behavior; [local verification](verification.md) records the initial service checks and [deployment status](deployment-status.md) records release and production evidence.

## Scope of completion

The backend, package, CLI/updater and UIArc store are implemented in this workspace. Authoring is part of the existing Accounts developer frontend, with Accounts settings retained in the same app workspace and no store discovery page. Native release artifacts, registry publication, live catalog installation, telemetry, backups and the shared portal cutover have separate evidence in [deployment status](deployment-status.md). Nine supported package targets do not imply nine provisioned production validation workers.
