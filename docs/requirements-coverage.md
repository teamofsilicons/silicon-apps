## Scope of completion

The backend, package, CLI/updater and UIArc frontend are implemented and runnable from this workspace. The native package and local Accounts-backed publishing/install/author flows have been exercised. Building this repository does not publish crates or release assets, migrate production data, configure DNS/Accounts credentials, deploy the two websites, or provision a fleet of operating-system workers. Those release operations and their acceptance checks are documented in [operations](operations.md) and [verification](verification.md).
